# oddz K-MOOC 오늘의 강의 v0.1.0

K-MOOC(`lms.kmooc.kr`)에서 여러 강좌의 영상을 골라 한 목록에 담고, 순서대로 이어서 재생하는 크롬 확장프로그램입니다. 인천대 버전(v0.2.7)을 바탕으로 만들었습니다. K-MOOC 강의실도 인천대 LMS와 같은 Moodle(Coursemos) 기반입니다.

> 실제 로그인 상태에서 연속 재생은 아직 확인하지 않은 시험판입니다. 이수 인정 여부는 K-MOOC 학습활동현황에서 직접 확인하세요.

## 설치

1. ZIP을 압축 해제합니다.
2. 크롬 주소창에 `chrome://extensions`를 입력합니다.
3. 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 안쪽의 `extension` 폴더를 선택합니다.
5. K-MOOC 내 강의실(`https://lms.kmooc.kr/`)을 새로고침하면 **오늘의 강의** 창이 나타납니다.

## 사용

1. 패널에서 강좌 이름을 눌러 강의실로 들어갑니다.
2. 들을 영상을 체크하고 **선택 영상 추가**를 누릅니다. 다른 강좌에서도 같은 방식으로 담습니다.
3. 순서를 확인하고 **전체 시작**을 누릅니다.
4. 영상이 끝나면 5초 뒤 다음 영상으로 이동합니다. 강좌가 바뀌면 내 강의실을 거쳐 이동합니다.

패널 제목 옆에는 오늘 목록의 총 재생 시간이 표시됩니다.

## 인천대 버전과 다른 점

- 영상 목록은 강의실의 `li.activity.modtype_vod` 항목에서 읽습니다. K-MOOC 영상은 링크 대신 `onclick`의 `window.open('.../mod/vod/viewer.php?id=N')`으로 열리기 때문입니다.
- 강좌 이름은 내 강의실의 강좌 카드 링크(`강좌명 + 운영 기간`)에서 읽습니다.
- K-MOOC는 영상을 팝업 창으로 열지만, 이 확장프로그램은 같은 탭에서 `viewer.php`를 엽니다.

## 확인이 필요한 부분

- 영상을 팝업이 아닌 같은 탭에서 열어도 재생과 진도 기록이 정상인지
- 자동재생이 차단되지 않는지. 차단되면 재생 버튼을 직접 눌러야 합니다.
- 강좌가 여러 개일 때 내 강의실을 거쳐 이동하는지
