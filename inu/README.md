# oddz LMS 오늘의 강의 v0.2.7 — 여러 과목 선택 재생

## v0.2.7 총 재생 시간 표시

패널 제목 `오늘의 강의` 옆에 오늘 재생할 목록의 영상 길이를 합산해 `총 1시간 36분`처럼 표시합니다. 펼친 패널과 접은 패널 모두 보입니다. 길이를 읽지 못한 영상이 있으면 `+α`가 붙고, 마우스를 올리면 빠진 개수가 나옵니다. 업데이트 방법은 아래 v0.2와 같습니다.

기존 v0.1의 한 과목 안 다음 영상 이동을 확장한 새 확장프로그램입니다.
사용자가 확인한 인천대 LMS 링크 구조를 바탕으로 작성했고 실제 로그인 세션에서의 여러 과목 실행은 아직 검증하지 않았습니다.

## 아이콘 표시

파란색 바탕의 흰색 재생 아이콘을 설치 목록과 크롬 도구 모음에 추가했습니다. 크롬 오른쪽 위 퍼즐 모양의 확장프로그램 메뉴에서 **oddz LMS 오늘의 강의** 옆 핀을 누르면 아이콘을 고정할 수 있습니다. 시작·중지와 목록 편집은 LMS 페이지 안의 패널에서 합니다.

## 창 높이와 스크롤 개선

바깥 창은 고정된 높이 안에서 표시하고, 영상 선택 목록과 오늘 재생 목록 안에서만 스크롤합니다. 대기 중 안내 상자는 제거했고 실행 상태·오류는 짧은 문구로 표시합니다. 버튼은 목록 아래에 항상 보이며, 창 높이에 맞춰 목록의 높이가 자동 조절됩니다.

## 목록 표시 개선

- 교수 전체 이름을 포함한 과목 링크를 우선 사용해 `장승수 - 형사법 (코드)` 형태로 표시합니다.
- 영상 제목의 선택 문구와 반복 제목을 정리하고 제목, 기간, 상태를 나눠 표시합니다.
- 제목은 굵게, 기간은 파란색, 완료는 초록색으로 구분합니다. 마감은 작은 주황색 표시로 남깁니다.
- 교수 전체 이름이 페이지에 없으면 추측하지 않고 과목명만 표시합니다. LMS 홈페이지를 먼저 열면 전체 이름을 읽어 같은 탭에서 유지합니다.

## v0.2에서 업데이트

기존 확장프로그램을 중지하고, 설치에 사용한 `extension` 폴더의 파일을 이번 버전으로 덮어쓴 뒤 `chrome://extensions`에서 해당 확장프로그램의 새로고침 버튼을 누르세요. LMS 탭도 새로고침하면 됩니다. 기존에 담은 목록은 같은 확장프로그램을 유지하면 보존됩니다.
새 폴더로 따로 설치할 때는 기존 v0.2를 끄고 시작하세요.

## 설치

1. **기존 v0.1 확장프로그램은 끄거나 제거하세요.** 두 프로그램을 함께 실행하지 않습니다.
2. ZIP을 압축 해제합니다.
3. 크롬 주소창에서 `chrome://extensions`를 엽니다.
4. 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
5. 이번 ZIP 안의 `extension` 폴더를 선택합니다.
6. LMS 홈페이지를 새로고침합니다. 화면 중앙에 **오늘의 강의** 창이 나타납니다.

## 오늘의 목록 만들기

1. 홈페이지 패널의 과목 이름을 누릅니다. 해당 과목의 주차 목록으로 이동합니다.
2. 영상이 안 나오면 LMS의 **자세히 보기**를 열고 **현재 페이지 다시 읽기**를 누릅니다.
3. 패널에서 듣고 싶은 영상만 체크합니다. 제목·기간·완료 여부는 원래 LMS 화면과 대조하세요.
4. **선택 영상 추가**를 누릅니다.
5. 홈페이지로 돌아와 다른 과목에서도 반복합니다. 기존 선택은 유지됩니다.
6. 오늘 목록의 ↑ ↓ 버튼으로 순서를 바꾸거나 삭제합니다.
7. 홈페이지에서 **전체 시작**을 누릅니다.

제목 링크와 아이콘 링크가 같은 영상을 가리키면 영상 번호로 하나만 추가합니다.
현재 페이지에 로드된 링크를 읽으므로 여러 주차와 숨겨진 항목도 목록에 포함될 수 있습니다.
완료한 영상과 시작 전 영상을 자동 제외하지 않습니다. 기본으로 아무 영상도 체크하지 않습니다.
첫 테스트는 두 과목에서 영상 1개씩만 선택해 진행하세요.

## 실행 흐름

- 시작한 탭 하나에서 선택한 영상의 `viewer.php?id=...` 화면을 엽니다.
- 자동 재생을 시도합니다. 차단되면 패널에 안내가 나오고 직접 재생 버튼을 누르면 됩니다.
- 실제 재생 진행을 관찰한 뒤 영상 종료 신호를 기다립니다.
- 끝나면 5초 대기 후 다음 **선택 영상**으로 이동합니다.
- 과목이 바뀌면 LMS 홈페이지에 돌아왔다가 2초 뒤 다음 과목의 선택 영상을 엽니다.
- 마지막 영상 종료 후 홈페이지로 돌아와 완료 팝업을 띄웁니다.

완료 팝업은 영상 재생 종료를 뜻합니다. 출석·진도 저장이나 인정 여부를 보장하지 않습니다.
5초 대기는 서버의 기록 저장 확인 신호가 아닙니다. LMS의 실제 기록을 확인해야 합니다.

## 중지·재개

- **중지**: 자동 이동을 끕니다. 영상 자체는 계속 재생될 수 있습니다.
- **이어서 시작**: 중지했던 영상부터 다시 엽니다. 영상 내 이어보기 시점은 LMS 동작에 따릅니다.
- **실행 초기화**: 자동 실행을 끄고 순서를 처음으로 돌립니다. 선택 목록은 유지합니다.
- **목록 비우기**: 대기 상태에서 선택을 모두 삭제합니다.
- 재생 중과 중지 후에는 순서 변경을 막습니다. 편집하려면 먼저 실행 초기화를 누르세요.
- 브라우저 재시작이나 실행 탭 닫기는 자동 실행을 중지합니다.
- 완료 후 전체 시작을 다시 누르면 선택 목록을 처음부터 재생합니다.

실행 중에는 같은 탭에서 직접 다른 강의를 열지 마세요. 다른 LMS 화면으로 이동하면 중지하도록 설계했습니다.
LMS 밖으로 이동하면 이 확장프로그램은 작동하지 않으므로, 다시 LMS에 돌아와 상태를 확인하세요.
영상이 45초 동안 나타나지 않으면 중지합니다. 로딩 지연·권한·수강 기간 문제를 확인하세요.
펼치면 중앙의 큰 창에서 영상 선택과 재생 목록을 나란히 확인할 수 있습니다.
패널이 가리면 **접기**를 누릅니다. 오른쪽 작은 패널로 바뀌며 선택·완료 개수가 표시됩니다.
**펼치기**를 누르면 다시 중앙으로 돌아옵니다. 접힌 상태는 같은 탭의 다음 LMS 페이지에서도 유지됩니다.
좁은 화면에서는 선택 영역과 목록이 위아래로 배치됩니다.

## 정보 저장과 권한

선택한 영상 이름·과목 이름·영상 번호·순서·진행 상태를 크롬 확장프로그램 로컬 저장소에 저장합니다.
외부 서버나 분석 서비스에 전송하지 않으며, 로그인 정보와 진도 기록을 읽거나 변경하는 기능은 없습니다.
LMS 홈페이지, 과목 페이지, 영상 화면에서 목록과 영상을 읽고 페이지를 이동하기 위해 인천대 LMS 도메인 접근 권한을 사용합니다.
목록은 브라우저에 남습니다. 목록 비우기 또는 확장프로그램 제거로 지울 수 있습니다.
지원 범위는 인천대 LMS의 `/course/view.php` 및 `/mod/vod/view.php`, `/mod/vod/viewer.php` 영상입니다.
학교의 자동 재생·이동 허용 여부는 별도로 확인해야 합니다.

## 시험 확인 항목

1. 과목 이름과 영상 목록이 맞는지
2. 중복 영상이 하나로 합쳐지는지
3. 선택하지 않은 영상은 실행하지 않는지
4. A 마지막 → 홈페이지 → B 첫 영상 순서인지
5. 자동 재생 또는 수동 재생 안내가 나오는지
6. 중지 후 더 이상 자동 이동하지 않는지
7. 마지막 종료 후 홈페이지에 완료 팝업이 나오는지
8. LMS에 정상 진도 기록이 남는지

이번 ZIP은 확장프로그램 업데이트만 포함합니다. 화면 인식 매크로는 v0.1 상태로 유지합니다.
