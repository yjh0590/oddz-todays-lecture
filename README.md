# 작업 인수인계

## 프로젝트 목표
인천대·가톨릭대 LMS에서 사용자가 선택한 여러 과목의 강의 영상을 한 목록에 모아 순서대로 실제 재생하고, 영상 종료 후 다음 강의로 이동하는 Chrome 확장프로그램이다. oddz 홈페이지에서 ZIP 다운로드와 설치·사용 안내를 제공한다. 스토어 등록 대신 개발자 모드로 직접 설치한다.

## 사용자 요구와 최종 홈페이지 구조
- 프로젝트 목록에는 ‘오늘의 강의’ 카드 하나만 유지한다. 학교별 프로젝트 카드를 따로 만들지 않는다.
- 기존 오늘의 강의 페이지를 유지하고 제목 옆에 `인천대ver / 가톨릭대ver` 버튼을 배치한다.
- `projects/todays-lecture.html`은 인천대, `projects/catholic-lms.html`은 가톨릭대 페이지다.
- 학교별 페이지에 다운로드 / 사용법 탭을 둔다. 학교 전환 시 테마와 사용법 탭의 `#guide`를 유지한다.
- 개발일지는 제품 설명에 길게 붙이지 않고 개발일지 목록과 별도 글로 제공한다.
- 인천대 화면 미리보기는 사용자가 제공한 실제 화면 이미지로 교체했다. 파란 둥근 사각형과 흰 재생 버튼 아이콘을 사용한다.
- 기존 테마·프로젝트·로또 관련 수정 등은 보존한다. unrelated 파일을 일괄 교체·삭제하지 않는다.

## 작업 내역
1. 예정 상태의 LMS 강의 재생 프로그램을 ‘오늘의 강의’로 활성화하고 다운로드·설치·사용·업데이트 안내를 추가했다.
2. 인천대 배포 ZIP을 v0.2.6으로 교체하고 아이콘·버전 표기를 맞췄다.
3. 실제 화면 미리보기 교체, 최근 업데이트 본문 제거, 별도 인천대 개발일지와 목록 링크를 추가했다. 설치 파일 업데이트 방법은 사용법에 남겼다.
4. 가톨릭대 v0.6.6 다운로드·사용 안내·디버깅 알림 설명과 별도 개발일지를 추가했다.
5. 사용자의 정정에 따라 목록 카드를 하나로 합치고 제목 옆 학교별 버튼으로 이동하는 구조로 바꿨다.
6. GitHub 배포 후 버튼이 일반 링크처럼 보인 문제는 강력 새로고침 후 사용자가 해결됐다고 확인했다. 이전 CSS 캐시가 원인으로 추정되며 독립적인 원인 재검증은 하지 않았다.

## 이번에 파일에서 확인한 최신 상태
가톨릭대 최신 소스는 v0.6.9다(홈페이지 다운로드도 v0.6.9). v0.6.6 소스와 ZIP은 정리하면서 삭제했다. 실제 LMS에서 성공했는지는 확인되지 않았다.

v0.6.6 대비 v0.6.9 코드에는 진단 상태 표시·저장, 종료 신호 전달 진단, 영상 종료 시 currentTime 초기화에 대응하는 maxObservedTime 기반 종료 판정 등이 추가돼 있다. 이 설명은 코드 비교 결과이며 실제 동작 검증 결과가 아니다.

## 설치 차이 — 반드시 유지
- 인천대: ZIP 압축 해제 → `extension` 폴더 선택. 바깥 `oddz-todays-lecture-v0.2.6` 폴더를 선택하면 매니페스트 오류가 난다.
- 가톨릭대: ZIP 최상위에 manifest.json이 있다. 압축 해제한 폴더 자체를 선택한다.
- 공통: `chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램을 로드합니다. 설치 폴더를 이동·삭제하지 않는다. 교체 후 확장프로그램과 LMS 탭을 새로고침한다.

## 인천대 기술 구조
- 대상: `https://lms.inu.ac.kr/*`, Manifest V3, storage 권한.
- `background.js`: 재생 목록·상태·탭 소유권·순서 이동·중지·재개를 관리한다. 저장 키는 `oddzLmsQueueV2`.
- `content.js`: LMS 과목/영상 목록 수집, 페이지 내 UI, 영상 상태 감지와 재생 시도.
- 완료 표시 100%를 종료 근거로 삼지 않고 현재 영상의 실제 종료를 기다리는 것이 설계 의도다.
- 선택한 영상 종료 → 대기 → 다음 선택 영상. 과목이 바뀌면 LMS 홈을 경유한다. 마지막 종료 후 홈으로 돌아와 안내한다.
- 자동재생이 차단되면 수동 재생이 필요할 수 있다.

## 가톨릭대 기술 구조
- 대상: Canvas `canvas.catholic.ac.kr`, CMS `cms.catholic.ac.kr`. LearningX 도구가 iframe에서 작동하고 UniPlayer가 재생한다.
- 강의 목록 선택자: `.xnlal-attendance-list-item`. 강의 항목 자체를 클릭한다.
- 다음 강의로 갈 때 상세 화면에서 먼저 목록으로 복귀하고 목록을 기다린 뒤 한 번 클릭한다. 반복 클릭은 로딩 재시작 문제를 일으켰던 이력이 있다.
- 짧은 preloader/오프닝과 실제 본편을 구분한다. 현재 cms-content.js의 본편 최소 길이는 60초이므로 짧은 본편 지원은 별도 확인이 필요하다.
- DOM click / video.play만으로 다음 문서 자동재생이 실패했던 이력이 있고, background가 CDP Runtime.evaluate의 userGesture=true로 UniPlayer의 `vc-front-screen-play-selected` 이벤트를 실행한다.
- `debugger` 권한을 사용하므로 실행 중 Chrome 상단 디버깅 안내가 표시될 수 있다.
- `cms-content.js` → LECTURE_FINISHED → background → ADVANCE_TO_NEXT_LECTURE → canvas-content.js 흐름으로 이어진다.
- `catholicDebugState` 진단 정보가 v0.6.9 UI에 표시된다.

- 가톨릭대 README의 첫 제목은 예전 v0.2.0 표기가 남아 있다. 현재 버전 판정은 manifest.json과 실제 파일로 한다.
- 가톨릭대 v0.6.9 UI 진단 상자에는 v0.6.8 문구가 남아 있다. 이번 인수인계에서는 원본을 고치지 않았다.
